# Operating Model Template

## Purpose

Document your client's target operating model. This template produces the operating model section of the final project report. Use the three transformation levers as your structure.

## Instructions

Complete all three parts. Do not skip the current state. A roadmap that only shows the target state cannot be validated or costed.

## Quality check

Before finalising:
- Both current state and target state are documented for the process, not only the target.
- Every team has a named mandate, a named dataset, and a named agile level.
- The single most important structural change is named and connected to a roadmap initiative.
- Every metric change names the old metric and the new metric.
- Every operating model item is tagged H1 or H2.
