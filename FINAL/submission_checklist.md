## Self-assessment before submitting

Work through these questions as a team before the 7 June deadline.

### Executive summary test
Read only the executive summary. Can a board member who has not seen the rest
of the report make an informed decision? If the answer is no, the executive
summary is not finished.

### Recommendation traceability test
Take each of the three reasons supporting the recommendation. Trace each reason
back to a specific finding in the analysis. If a reason cannot be traced, it is
not yet evidence-based.

### Roadmap completeness test
Take any two initiatives at random. Do both have all seven elements? If not,
complete the remaining elements before submitting.

### Governance specificity test
Read the human override protocol for the highest-risk AI use case. Does it
state a specific measurable trigger threshold? Does it name a role (not a
person) as override authority? Does it state a maximum review time? If any
answer is no, revise before submitting.

### Responsible AI test
Read the responsible AI assessment. For the highest-risk AI use case, can you
state in one sentence what bias risk exists, in one sentence what transparency
obligation applies, and in one sentence who is accountable for an adverse
outcome? If not, the section is not complete.

### Change management budget test
Divide the change management budget by the total transformation cost. Is the
result between 20 and 30 percent? If below 20 percent, the budget is
underestimated. Revise.
